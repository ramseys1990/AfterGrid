Regional map downloads

Extract a regional Protomaps archive, not the whole planet. Select a published build date from the official builds list. The region is sent to the upstream archive service via range requests. Enter west, south, east and north in decimal degrees. Zoom controls detail and storage.

Drag a rectangle to select an area. Numeric bounds below can be edited directly. Natural Earth overview; not a navigation map. Presets are approximate rectangles, not political boundaries.

Existing PMTiles are never overwritten. Restart the Maps module after completion. Extracts are structurally verified, not checked against a full planet checksum. Map rendering currently uses the native inspection viewer.

Regional routing datasets

Download a Geofabrik OpenStreetMap PBF for Valhalla. This is separate from the visual map. A verified download is staged without modifying the existing graph. Graph building requires additional RAM and disk; start with a small region.

Preparing a replacement does not switch the running graph. Activation or rollback briefly stops routing. Archive only the inactive slot to prepare another update. Archiving retains the source and graph on disk; it does not reclaim space. Do not modify routing files during graph maintenance.

Backup coverage

Kopia manages encrypted repositories and snapshot policies. These source plans identify required files, not existing or verified backups. Never snapshot live databases without a consistent export or a maintenance stop.

Kopia repository

Before creating a new repository, save the generated repository password securely off-server and verify that your intended backup drive is mounted at the configured destination. Existing repositories must be connected in Kopia itself.

Native backup policies

Inspect effective Kopia scheduling and retention settings. Do not schedule live database or temporary export paths directly. Use managed schedules below for guarded snapshots.

Managed snapshot schedules

Opt in to daily or weekly snapshots using the existing worker. Application snapshots may stop and restart the application. Busy or maintenance periods defer execution. Successful scheduled snapshots are verified using their exact source job; content uses read verification, databases and applications use isolated restore checks.

Recovery inventory

List existing exact snapshots and recorded verification. This is not a complete recovery package. Save the inventory off-server with your recovery records.

Each application card has its own backup source plan. Use Kopia's native interface to configure the repository; keep recovery credentials and an independent repository copy outside this server.
