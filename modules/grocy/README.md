# Grocy

Install from the portal; open http://127.0.0.1:8083 (SSH forward port 8083 for a remote host). Default native credentials are admin/admin; change them immediately. The development module stays loopback-only until guided LAN setup exists. Use storage locations for each household and shared supplies, and native stock, recipes and expiration tracking. Data lives in data/grocy. Removal preserves data. No cross-module inventory sync or household mapping yet.

See [LAN access](../../docs/LAN_ACCESS.md) for explicit sharing after changing the native default password.
