# Grocy

Install from the portal and choose Set up native account on its card as AfterGrid administrator. Replace the native admin/admin default password through the supported local login/user APIs, or verify an existing admin account. The flow verifies the new login and checks that the default password is rejected; it does not reset an unknown existing password. Save the password, then explicitly Share on LAN. Native login remains required; the application stays loopback-only during setup and the portal does not store its password. Use storage locations for each household and shared supplies, and native stock, recipes and expiration tracking. Data lives in data/grocy. Removal preserves data. No cross-module inventory sync or household mapping yet.

See [LAN access](../../docs/LAN_ACCESS.md) for explicit sharing after changing the native default password.
